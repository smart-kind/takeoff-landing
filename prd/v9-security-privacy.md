## 13. 安全与隐私

### 13.1 核心原则

| 原则 | 说明 |
|------|------|
| **本地优先** | 用户数据优先存储在本机，非必要不上传云端 |
| **数据最小化** | 只收集功能必需的最少数据 |
| **用户掌控** | 用户随时可以导出、删除自己的全部数据 |
| **AI 透明** | 用户清楚知道哪些数据会发送给 AI，哪些不会 |

### 13.2 数据安全

#### 传输安全
- 全站 HTTPS（生产环境）
- API 请求签名验证

#### 存储安全
- 密码 bcrypt 哈希存储
- SQLite 文件可选加密（SQLCipher）
- 敏感字段（API keys）加密存储

#### AI 数据脱敏
- 发送给 LLM 的数据自动脱敏：
  - 移除个人身份信息（姓名、邮箱、手机号）
  - 移除敏感商业数据（营收、融资额）
  - 用户可选择关闭云端 LLM，仅用本地模型

### 13.3 隐私合规

#### 国内合规

| 法规 | 要求 | 应对措施 |
|------|------|----------|
| **个人信息保护法 (PIPL)** | 明示收集目的、取得同意 | 隐私政策清晰告知，用户勾选同意 |
| **数据安全法** | 重要数据本地存储 | 核心数据优先本地 SQLite |
| **ICP 备案** | 网站需备案 | 按落地指南模块要求执行 |

#### 国际合规

| 法规 | 要求 | 应对措施 |
|------|------|----------|
| **GDPR** | 数据主体权利、DPO | 用户可导出/删除全部数据 |
| **CCPA** | 加州消费者隐私权 | 提供"Do Not Sell"选项 |

### 13.4 权限模型

| 阶段 | 权限 | 说明 |
|------|------|------|
| MVP | 无需注册 | 所有数据存储在浏览器 localStorage |
| v1.1 | 邮箱注册 | 用户数据云端同步 |
| v2 | 角色权限 | 个人用户 / 团队管理员 / 团队普通成员 |
